개인정보 처리방침

시행일: 2026년 10월 8일

스트리머 메신저(이하 “서비스”)는 서비스 제공에 필요한 정보만 처리하고, 처리 목적·항목·보유기간과 권리 행사 방법을 아래와 같이 안내합니다.

1. 처리하는 정보와 목적

  • 계정·인증: Firebase UID, 로그인 제공자와 연결 상태, 제공자가 전달하는 이메일 등 인증 정보, 스트리머 인증·계정 전환 상태를 로그인 유지, 본인·권한 확인, 계정 보호 및 이용 제한에 사용합니다. 인증되지 않은 방문에는 임시 익명 UID가 만들어질 수 있으며, 익명 계정만으로는 메시지 전송·신청·거래 등 제한된 기능을 사용할 수 없습니다.
  • 브라우저 저장 정보: Firebase 로그인 상태를 브라우저 저장소에 유지합니다. 계정 전환 승인 요청의 중복 처리를 막는 식별자와 시각을 브라우저의 localStorage에 짧게 저장하고, 절차가 끝나면 지우거나 재시도 제한 시간이 지나면 더 이상 사용하지 않습니다. 브라우저 저장 정보를 삭제하면 로그인 상태가 풀릴 수 있습니다.
  • 프로필·방 참여: 사용자가 입력한 SOOP 닉네임·아이디·프로필 사진, 대화 신청 소개, 신청·승인·참여·차단 상태와 시각을 프로필 표시, 방 운영 및 참여 권한 확인에 사용합니다. SOOP 계정의 실제 소유 여부는 확인하지 않습니다.
  • 대화·첨부: 메시지 내용, 작성 시각, 발신 UID와 역할, 답변·수신 대상, 표시용 닉네임·프로필 사진을 대화 제공과 신고 처리에 사용합니다. 갤러리 이미지는 스트리머 갤러리의 이미지 ID를 참조합니다. 팬별 대화는 해당 팬과 스트리머에게 표시되며 다른 팬에게 공개되지 않습니다. 신고가 접수되면 신고 검토를 위해 선택된 대화와 이미지 증거를 지정된 관리자에게 제공할 수 있습니다.
  • 방셀 이미지: 스트리머가 선택한 팬에게만 보내는 이미지 파일, 파일 형식·크기, 업로더·수신자·전송 시각과 접근 식별 정보를 처리합니다. 이 이미지는 공개 스트리머 갤러리에 등록되지 않습니다.
  • 신고·안전 운영: 신고 사유와 설명, 신고 대상·신고자 UID, 선택한 대화 범위, 검토용 메시지·이미지 증거, 처리 상태와 관리자 조치 기록을 신고 검토, 분쟁 대응 및 계정 보호에 사용합니다. 반복 전송 제한을 위해 서버가 메시지 전송 시각과 위반·대기 상태도 처리합니다.
  • 참여방 바로가기: 사용자 UID와 참여 중인 방 ID·가입 시각을 연결한 인덱스를 저장해 재접속 시 참여방을 빠르게 보여줍니다. 방 참여 상태가 종료되면 인덱스를 갱신하거나 삭제합니다.
  • 채팅방 종목·거래: 방 공유 종목과 방별 최근 거래 피드(종목 ID·이름, 매수/매도 구분, 수량, 체결가, 시각, 공개를 선택한 경우 닉네임)를 채팅방 내 공유와 거래 표시를 위해 처리합니다. 개인의 모의 현금·보유 종목 등 계정 상태는 기존 스트리머 주식시장 거래 시스템에서 처리됩니다.
  • 접속·알림: 접속 상태 집계를 위해 UID별 최근 접속 시각을 갱신합니다. 브라우저 알림은 사용자가 브라우저 권한을 허용한 경우 현재 페이지가 열려 있을 때 새 메시지나 신청 상태를 표시합니다. 페이지가 닫혀 있는 동안 푸시 알림은 발송하지 않습니다.

2. 보유 및 삭제 기간

  • 대화 메시지는 작성 시각으로부터 7일이 지난 뒤 매일 실행되는 정리 작업에서 삭제합니다. 정리 작업 시각에 따라 실제 삭제 시점에 짧은 차이가 생길 수 있습니다.
  • 방셀 이미지는 메시지와 함께 기본적으로 7일 후 정리합니다. 신고에 포함된 이미지 증거는 신고 접수 시각부터 최대 14일 보관되며, 보관기간이 지난 뒤 정리 작업에서 삭제합니다. 갤러리 원본 이미지의 보관은 스트리머 갤러리 정책을 따릅니다.
  • 신고와 검토용 증거는 접수 후 최대 14일 보관합니다. 신고 검토용 감사 기록은 최근 200건으로 제한합니다.
  • 대화 신청은 대기 상태로 최대 3일 유지한 뒤 만료 처리합니다. 방 참여·차단 상태와 방 설정은 해당 상태가 해제되거나 방이 폐기될 때까지 보관합니다.
  • 방별 종목 목록은 스트리머가 제거하거나 방이 폐기될 때까지 보관합니다. 메신저 거래 피드는 방마다 최근 100건만 유지합니다. 모의 현금·보유 종목 등은 기존 주식시장 계정 기록에서 처리되며, 그 서비스의 보유 기준을 따릅니다.
  • 접속 상태는 UID별 최근 시각을 덮어써 저장하며 별도의 접속 이력 목록을 만들지 않습니다. 서비스별 계정·프로필 데이터의 삭제를 요청하면 본인 확인 후 다른 서비스나 법령상 보관 의무에 영향을 주지 않는 범위에서 처리합니다.
  • 신고·분쟁 대응 또는 법령상 보존 의무가 있는 경우에는 필요한 항목을 해당 기간 동안 분리 보관할 수 있습니다. Firebase·Cloudflare·GitHub 등 제공자가 자체적으로 생성하는 보안·접속 로그의 보유기간은 각 제공자 정책을 따릅니다.

3. 외부 서비스와 국외 처리

  • Google LLC / Firebase: 로그인 인증, Realtime Database 및 Cloud Functions를 제공합니다. Firebase 데이터베이스와 서버 기능은 미국 us-central1 리전에서 운영됩니다. 계정·프로필·방·메시지·신고·종목 공유 데이터가 서비스 제공을 위해 처리될 수 있습니다.
  • Cloudflare, Inc. / R2: 방셀 이미지와 신고 검토에 필요한 임시 이미지 증거를 저장·전달합니다. 메신저 비공개 R2 버킷은 Cloudflare 계정에서 아시아 태평양 위치로 설정되어 있습니다.
  • GitHub, Inc. / GitHub Pages: 정적 웹페이지를 호스팅하며, 페이지 접속 과정에서 IP 주소·브라우저·접속 시각 등 기술 정보가 제공자에 의해 처리될 수 있습니다.
  • Google·Kakao 로그인 제공자: 이용자가 해당 로그인을 선택한 경우 로그인 인증을 처리합니다. 인증 제공자가 처리하는 정보와 보유기간에는 각 제공자의 정책이 적용됩니다.
  • SOOP 및 스트리머 주식시장: 공개 스트리머 프로필·이미지와 기존 모의 주식 시세·거래 기능을 연결합니다. SOOP 아이디 소유 여부를 인증하거나 실제 금융상품을 거래하지 않습니다.

위 처리는 서비스 요청 시 HTTPS를 통해 이루어집니다. 외부 사이트·플레이어·인증 SDK를 직접 열거나 이용하면 해당 제공자가 브라우저 접속 정보를 직접 처리할 수 있습니다. 서비스는 각 제공자의 자체 로그 보유기간을 통제하지 않습니다.
