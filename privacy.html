처리하는 정보와 목적

Firebase UID와 로그인 연결 상태는 계정 확인·접근 제어에 사용합니다. 사용자가 설정한 프로필 사진·SOOP 닉네임·SOOP 아이디, 선택 입력한 대화 신청 소개, 방 신청·승인 상태, 대화 메시지, 신고·제재 정보와 운영 감사 기록은 프로필 표시, 대화 제공, 안전한 운영 및 신고 처리에 필요한 범위에서 처리됩니다. SOOP 아이디의 실제 소유 여부는 확인하지 않습니다. Google·Kakao 로그인 인증은 Firebase 및 해당 제공자가 처리하며, 서비스 프로필에는 이용자가 입력한 값만 사용합니다.

서비스는 UID별 접속 시각을 접속 상태 집계에 사용합니다. 브라우저 알림은 이용자가 권한을 허용한 경우에만 사용합니다.

보관 및 삭제

대화 메시지는 매일 정리 작업을 통해 최대 7일 보관합니다. 신고자는 아직 삭제되지 않은 대화 중 최대 1일 범위를 선택해 신고할 수 있으며, 신고와 검토용 증거는 접수 시점부터 최대 14일 보관한 뒤 삭제합니다. 운영 감사 로그는 최근 200건으로 제한됩니다. 계정·프로필·방 신청 정보는 서비스 제공과 분쟁 대응에 필요한 동안 보관하고, 삭제 요청 또는 목적 달성 후 법령상 보존 의무가 없는 범위에서 삭제합니다.

이미지 및 외부 처리자

갤러리 이미지는 스트리머 갤러리의 이미지 ID를 참조합니다. 스트리머가 보내는 방셀 이미지는 별도 Cloudflare R2 버킷(streamer-messenger-private)에 저장되며, 접근 권한 확인을 거쳐 전달됩니다. 신고용 증거 이미지는 갤러리 또는 메신저 R2에 임시 보관될 수 있고, 신고 보관 기간 종료 시 정리됩니다.

  • Google LLC (Firebase / Google Cloud): 인증, 데이터베이스 및 서버 기능
  • Cloudflare, Inc. (R2): 메신저 방셀 이미지와 임시 신고 증거 저장·전달
  • Kakao Corp.: 이용자가 Kakao 로그인을 선택한 경우 로그인 인증
  • GitHub Pages: 정적 웹페이지 호스팅 및 접속 로그 처리

국외 이전: Firebase Realtime Database 인스턴스는 미국(us-central1)에 있습니다. 서비스 이용 시 Firebase UID와 위에 기재한 계정·프로필·메시지·신고 정보가 HTTPS를 통해 Google LLC의 미국 인프라로 전송·저장될 수 있으며, 인증·데이터베이스·서버 기능 제공에 이용됩니다. 보유 기간은 위 보관 항목을 따릅니다. Cloudflare R2의 이미지 파일은 별도 Cloudflare 설정에 따라 국외에서 처리될 수 있으며 실제 저장 위치와 국가를 확인해야 합니다.

각 제공자는 서비스 제공에 필요한 범위에서 정보를 처리하며 자체 보안·접속 로그의 보유기간은 제공자 정책을 따를 수 있습니다.
